# راهنمای تغییر رمز عبور حذف ریویژن

## رمز عبور پیش‌فرض
رمز عبور پیش‌فرض برای حذف ریویژن: **987654321**

## نحوه تغییر رمز عبور

### روش 1: استفاده از فایل .env (توصیه می‌شود)

1. به پوشه بک‌اند بروید:
   ```
   cd simorgh-agent/simorgh-soft/simorgh-backend
   ```

2. فایل `.env` را باز کنید (یا ایجاد کنید):
   ```
   nano .env
   ```

3. خط زیر را اضافه یا ویرایش کنید:
   ```
   REVISION_DELETE_PASSWORD=رمز_جدید_شما
   ```

4. سرور را ری‌استارت کنید:
   ```
   npm restart
   ```

### روش 2: تغییر مستقیم در کد

1. فایل `server.js` را باز کنید
2. به خط 1152 بروید
3. مقدار پیش‌فرض را تغییر دهید:
   ```javascript
   const correctPassword = process.env.REVISION_DELETE_PASSWORD || 'رمز_جدید_شما';
   ```

## نکات امنیتی

- رمز عبور باید حداقل 8 کاراکتر باشد
- از ترکیب حروف، اعداد و نمادها استفاده کنید
- رمز عبور را در جایی امن ذخیره کنید
- هرگز رمز عبور را با دیگران به اشتراک نگذارید

## موقعیت‌های استفاده از رمز عبور

رمز عبور فقط در زمان حذف ریویژن درخواست می‌شود:
- کلیک روی دکمه حذف در dropdown ریویژن
- وارد کردن رمز در مودال تأیید
- تأیید حذف ریویژن

## توجه

- ریویژن 0 (BASE) قابل حذف نیست
- فقط ریویژن‌های جدیدتر از BASE قابل حذف هستند
- پس از حذف ریویژن، داده‌های آن برای همیشه پاک می‌شوند
