# Cleanup notes (June 2026, paired with Dockerfile bump to 2.6.0 base):
#
# REMOVED (with rationale):
#   torch==2.5.0                — the pytorch/pytorch:2.6.0 base ships
#                                 torch via conda. Re-pinning in pip would
#                                 fetch the 906 MB wheel on every layer
#                                 rebuild because pip doesn't see conda-
#                                 installed packages as satisfying. The
#                                 conda torch is what sentence-transformers
#                                 / transformers actually load at runtime.
#   unstructured[local-inference] — never imported anywhere in this service
#                                 (grep confirmed: zero call sites). The
#                                 [local-inference] extras pull onnx +
#                                 layoutparser + detectron2 deps, adding
#                                 ~2 GB to the image for nothing.
#   pdfminer.six                — only used by cocoindex_flows/industrial_
#                                 electrical_flow.py:314. The production
#                                 path delegates all PDF extraction to the
#                                 doc-processor service over HTTP via
#                                 services/doc_processor_client.py. The
#                                 CocoIndex flow should likewise call
#                                 doc-processor; leaving it stuck on
#                                 pdfminer is now a known TODO, not a
#                                 reason to bundle 50 MB of pdfminer here.
#   pdf2image, pytesseract,     — OCR + page rendering. Never imported in
#   opencv-python-headless,      this service. All of this lives behind
#   Pillow                       doc-processor:8000/process which already
#                                 handles PDFs, images, and OCR centrally.
#                                 Pillow ships transitively with sentence-
#                                 transformers if it's needed at runtime.
#
# Disk savings: ~2-3 GB on the documents-rag image.
# Build savings: ~6-8 minutes off `pip install` on a slow link.
# =============================================================================
